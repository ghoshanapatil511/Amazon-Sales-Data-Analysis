# **Amazon-Sales-Data-Analysis**
### **Amazon Sales Data Analysis using Python and data visualization.**


## **📌 Project Overview**

This project analyzes Amazon product data to understand prices, discounts, product categories, and customer ratings using Python.

## **🎯 Project Objectives)**

- Analyze product ratings ⭐
- Explore discounts and ratings 💰
- Find the top 10 product categories 📊
- Understand category-wise product distribution 📈

## **🛠️ Tools & Libraries**

- 🐍 Python
- 🐼 Pandas
- 🔢 NumPy
- 📊 Matplotlib
- 🎨 Seaborn
- ☁️ Google Colab

## **📂 Dataset Information**

The dataset contains product names, categories, actual prices, discounted prices, discount percentages, ratings, and customer reviews.

## **🔄 Project Workflow**

1. 📥 Data Loading
2. 🔍 Data Understanding
3. 🧹 Data Cleaning
4. 📊 Exploratory Data Analysis (EDA)
5. 📈 Data Visualization
6. 💡 Insights and Interpretation

## **💡 Key Insights**

Explores patterns in product ratings, discounts, and category-wise product distribution.

## **📈 Business Recommendations**

Helps understand product categories, pricing, discounts, and customer ratings based on the analysis.

## **⚠️ Limitations**

The analysis depends on the available dataset and its data quality.
